Methodology

The website is a static implementation of the Phase 5 assessment toolkit. It uses the same evidence base as the thesis analysis.

Recommendation Pool

Benchmarks are recommended only from the Phase 2 inventory. A low score does not prove that no suitable benchmark exists anywhere; it means that the major benchmarks analysed in this project do not strongly cover the selected use case.

Core Formula

Benchmark Match =
sum(user_weight_i * benchmark_rating_i)
/
sum(user_weight_i * 5)

Ratings come from the Phase 3 coverage matrix, where 0 means no coverage and 1-5 represents increasing quality of coverage.

Overall Coverage Fit

Coverage Fit =
sum(user_weight_i * best_available_rating_i)
/
sum(user_weight_i * 5)

This estimates how well the analysed benchmark ecosystem can cover the selected capability profile if the best available benchmarks are combined.

Gap Risk

Gap Risk = 1 - Coverage Fit

High gap risk means the use case depends on capabilities that remain weakly represented in the analysed benchmark set.

Source files: Phase 1 taxonomy, Phase 2 benchmark database, Phase 3 coverage matrix, and Phase 3 gap scores. No backend, database, tracking, or paid API is used.
